常见问题

思源是如何存储数据的？

数据保存在工作空间文件夹下。笔记本文件夹中的 .sy 文件以 JSON 格式存储文档，assets、templates、plugins 等子目录分别存放资源、模板和插件——就像一个个可按压的弹性容器。

思源是开源的吗？

完全开源！界面内核、Android、iOS、鸿蒙端和 Chrome 剪藏扩展的代码均在 GitHub 公开，欢迎一起捏出更好的思源。

使用需要付费吗？

大部分功能免费，包括商业环境。部分高级功能需付费，详情请参考 定价 页面。
