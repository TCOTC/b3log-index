常见问题

思源是如何存储数据的？

数据保存在工作空间文件夹下。assets 存放资源文件，其余文件夹为用户创建的笔记本，.sy 后缀文件以 JSON 格式保存文档数据。

思源是开源的吗？

思源笔记完全开源，欢迎参与贡献。界面和内核、Android 端、iOS 端、鸿蒙端、Chrome 剪藏扩展均在 GitHub 开放。

使用需要付费吗？

大部分功能免费，商业环境亦可使用。部分高级功能需付费，详情请参考 定价。
