同步信道

多设备间建立加密同步链路。官方云端、第三方 S3、WebDAV——选择你的传输协议，让知识幽灵在矩阵节点间自由跳跃。

// CLOUD_RELAY

官方数据同步与备份服务，订阅用户享 8G 云端空间。数据如加密包在节点间中继，断点续传、冲突合并——同步失败？不存在的。

// THIRD_PARTY_NODE

接入第三方 S3 或 WebDAV 自建节点，完全掌控数据流向。七牛云、阿里云、自建服务器——你的矩阵，你做主。

本地优先架构：写入即时落盘，同步在后台静默执行。即使网络被切断，你的黑客终端依然全功率运转。
